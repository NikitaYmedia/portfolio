# Portfolio — Nikita Yeltsov

Pure HTML + CSS + JS. HTML has no styles: all visuals (incl. icons) live in `css/`.

- `index.html`, `projects.html`, `admin.html`
- `css/` base, layout, pages, reviews
- `js/` main (UI), i18n (EN/DE/DA/UA), reviews + api + config (Supabase), admin
- `fonts/` Archivo + Inter (local), `img/`, `cv/`, `supabase.sql`

Run locally: `python3 -m http.server` and open http://localhost:8000
